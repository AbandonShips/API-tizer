# ![API-tizer 로고](./favicon.png) API-Tizer

**현재 버전: v1.3.0**

ChatGPT · Claude · Gemini · Grok · 로컬 OpenAI 호환 모델을 한 화면에서 동시에 호출하고 비교하는 개인용 멀티 AI 콘솔입니다.

- 여러 모델 동시 응답, 분할/통합 보기, 마스터 요약
- 마스터 요약이 성공한 턴은 후속 질문에 **공식 종합 + 모델별 직전 답**을 함께 넘겨 대화 연속성과 다양성을 유지
- 마스터 요약 옆 **일치/이견 배지**(✓ 일치 · ⚠ 이견)로 모델들이 갈릴 때(환각 의심 신호)를 한눈에 파악
- **마스터 OFF에서도 앙상블 가치** — 답변들의 유사도로 턴마다 일치/갈림 신호(추가 비용 없음)와, 원할 때 🔍 교차검증(한 모델이 “답이 어디서 갈리는지”만 짚어 줌)
- **마스터(집계자) 대체** — 마스터 모델이 타임아웃·실패하면 다른 완료 모델을 골라 요약을 수행할 수 있습니다
- 긴 대화 **자동 압축(컴팩션)** — 대화가 길어져 매 질문에 실리는 이전 맥락이 커지면 안내하고, 이전 대화를 하나의 요약으로 접어 토큰을 절약합니다(채팅 화면 내용은 그대로 유지). 상단 🗜 대화 압축 버튼으로 언제든 수동 실행 가능
- 토큰 절약형 히스토리 관리 — 최근 대화는 원문, 오래된 대화는 공식 종합만, 첨부(이미지·PDF)는 최근 것만 재전송
- 이미지 · 텍스트 · PDF 첨부
- 웹 검색 지원 모델의 출처 표시, 본문 URL 자동 링크화, 이미지 링크 미리보기
- 설정의 "풍부한 응답 서식" (기본 ON)으로 API 호출 시에도 이모지·표·구조화된 답변 유도 (웹 ChatGPT 느낌에 가깝게)
- 채팅별 📝 전용 프롬프트 지원 — 채팅 제목 옆 📝 버튼으로 특정 채팅에서만 적용되는 시스템 프롬프트 설정 가능 (설정 시 전역 취향 프롬프트를 대체, 플랫폼 기본 연속성 지시는 유지)
- 채팅 전용 프롬프트 설정 시 풍부한 응답 서식(이모지·표·구조화) on/off를 독립적으로 제어 가능 (새 채팅 직후에도 설정 가능)
- 모델 응답 및 마스터 요약 타임아웃(기본 60초, 설정에서 초 단위로 조정 가능) + 진행 중 완료된 모델만 선택해 즉시 요약 실행 지원
- 최대 응답 토큰 설정(기본 8192) — Claude처럼 상한이 필수인 모델의 긴 요약·답변이 잘리지 않도록 조정 가능
- 모델별 토큰/비용 추정치 누적 (에러·타임아웃·부분 응답 시에도 정확히 카운트) 및 접이식 비용 패널
- 주요 제공자 모델 프리셋과 단가 자동 입력
- 로컬 암호화 저장 또는 Cloudflare Worker 기반 온라인 동기화
- PC/모바일 레이아웃 자동 전환 및 수동 고정

## 변경 사항

### v1.3.0

- 멀티턴 대화 히스토리를 개선했습니다. 마스터 요약이 **성공한 턴**에서는 후속 질문 시 각 모델에 **공식 종합(사용자가 본 축)** 과 **그 모델이 그 턴에 제출한 개별 답**을 함께 이전 맥락으로 보냅니다. 마스터가 꺼져 있거나 실패한 턴은 기존처럼 해당 모델의 개별 답만 사용합니다.
- 다른 모델의 원문은 서로 히스토리에 넣지 않아, 모델별 관점·개성은 유지하면서도 「옵션 A로 해줘」처럼 요약에만 있는 전제를 전 모델이 공유할 수 있게 했습니다.
- 마스터 요약 호출(`runMaster`)에는 **가장 최근 성공한 공식 종합 1장**을 참고로 붙입니다. 이번 질문과 이번 각 모델 답을 주 재료로 두고, 이전 종합은 용어·선택지·결론 연속용으로만 사용합니다. 과거 요약을 전부 쌓아 보내지는 않습니다.
- 플랫폼 기본 연속성 지시(공식 종합 vs 내 이전 답 해석)를 시스템 프롬프트에 항상 포함하고, 전역·채팅 전용 취향 프롬프트는 **배타 1칸**(채팅 전용 있으면 전역 취향 대체)으로 유지했습니다. 풍부한 응답 서식 토글·프롬프트 라이브러리(입력창 삽입) 동작은 그대로입니다.
- 마스터 토글을 대화 중간에 껐다 켜도, **그 턴에 저장된 상태**만으로 히스토리를 해석합니다. 지금 토글이 꺼졌다고 해서 이미 성공한 과거 공식 종합을 기억에서 지우지 않습니다.
- 다크 모드에서 브라우저 자동완성으로 아이디·비밀번호 등 입력창 배경이 하얗게 덮이던 문제를 수정했습니다. 로그인·설정·백업 암호 등 주요 입력 필드에 공통 대응을 적용했습니다.
- **긴 대화 자동 압축(컴팩션)**을 추가했습니다. 대화가 길어져 매 질문에 함께 실리는 이전 맥락의 분량(토큰)이 커지면 안내 팝업이 뜨고, 동의하면 이전 대화를 하나의 요약으로 접습니다. 채팅 화면의 기존 내용은 그대로 남고 요약 카드가 하나 추가되며, 이후 질문에는 (요약 + 최근 대화)만 전송돼 토큰이 절약됩니다. 상단바 🗜 대화 압축 버튼으로 원할 때 수동 압축도 가능합니다.
- **토큰 절약형 히스토리 관리**를 도입했습니다. 최근 대화는 원문(공식 종합+내 답)으로, 오래된 대화는 공식 종합만(척추)으로 보내고, 이미지·PDF 첨부는 최근 몇 개 질문까지만 원본을 재전송한 뒤 이후에는 요약 참조로 대체합니다. 사이드바 누적 비용 옆 ? 에 토큰이 늘어나는 요인 설명을 추가했습니다.
- **일치/이견 배지**를 마스터 요약 카드에 추가했습니다. 마스터의 소수 의견 판단을 읽어 모델들이 대체로 일치하면 ✓ 일치, 이견이 있으면 ⚠ 이견을 표시하고(통합 뷰에서는 카드 테두리도 강조) 환각 가능성이 있는 지점을 빠르게 알 수 있게 했습니다.
- **부재 모델 재합류**를 추가했습니다. 타임아웃·오류로 어떤 턴에 응답하지 못한 모델도, 그 턴의 공식 종합이 있으면 「내 답은 아니지만 그룹의 공식 결론」으로 받아 다음 질문에서 맥락이 끊기지 않게 했습니다.
- **최대 응답 토큰 설정**(기본 8192)을 추가했습니다. Claude(Anthropic)는 이 값이 필수라 낮으면 긴 마스터 요약이 잘리던 문제를 해결했습니다.
- 마스터 모델의 API 키가 없으면 그 턴만 자동으로 요약을 끄고 안내하도록(무의미한 에러 카드 대신) 개선했습니다.
- 중간 턴을 재생성할 때 뒤 턴이 과거처럼 히스토리에 섞이던 문제, 조기 요약 팝업·전송 재진입 정리, 비전(이미지) 토큰 추정 누락 등을 수정하고 안정화했습니다.
- 모바일에서 답변 카드 헤더가 좁은 화면에서 잘리지 않도록 줄바꿈 처리하는 등 반응형을 보완했습니다.
- **마스터 요약을 “합의/상충/소수” 3층 구조**로 개선했습니다. 여러 모델이 갈리는 사실을 임의로 지우지 않고 “A는 X, B는 Y”처럼 드러내며, 다수 공통은 핵심으로·한 모델 주장은 구분하고, 없는 사실을 지어내지 않도록 했습니다(환각 감소).
- **마스터 OFF 앙상블 가치**를 추가했습니다. 마스터를 안 켜도 답변들의 문자 유사도(바이그램, 한국어 조사 차이에 강건)로 “일치/갈림” 신호를 턴마다 보여주고(무비용), 원할 때 🔍 교차검증으로 한 모델이 답들의 공통·상충 지점만 짚어 줍니다.
- **마스터(집계자) 대체**를 추가했습니다. 마스터 모델이 타임아웃·실패하면, 요약 모델(집계자)과 포함할 답변을 팝업에서 골라 다른 모델로 요약할 수 있습니다(마스터 카드에 “대체” 표시).
- 백업에 최대 응답 토큰·사용량 시작시간이 빠지던 점, “새 채팅”이 웹 검색 선호를 매번 켜짐으로 덮어쓰던 점, 온라인 비밀번호 변경 중 세션이 끊기면 크래시나던 문제 등을 수정했습니다.
- **분할 보기에서 마스터 요약을 켜면** 모델 카드가 왼쪽으로 쏠리고 오른쪽이 비던 레이아웃 문제를 고쳤습니다. 이제 모델 카드가 화면 폭을 꽉 채우고, 마스터 요약은 그 아래 전체 폭으로 표시됩니다.
- **마스터 OFF 교차검증 버튼**을 개선했습니다. 답변이 도착하는 동안은 회색 비활성으로 대기하고, 모든 모델이 끝나면(또는 타임아웃) 활성화돼 눌러서 교차 확인할 수 있습니다.
- **안내 팝업을 화면 중앙에 크게** 표시하도록 바꿨습니다(이전에는 하단에 작게 떠서 놓치기 쉬웠습니다).
- 상단 수동 압축 버튼 이름을 **“🗜 대화 압축”**으로 바꾸고, 채팅이 열려 있으면 항상 보이도록(아직 짧으면 흐리게) 해 눈에 잘 띄게 했습니다.
- 도움말(?)을 **초보자용으로 다시 썼습니다**(마스터 ON/OFF 중심, 기술 용어 제거, 항목 간 여백으로 가독성 개선).
- 제공자별 **모델 목록과 예상 단가를 최신으로 갱신**했습니다(OpenAI GPT-5.6 Sol/Terra/Luna, Claude Sonnet 5, Grok 4.5 등 — 코딩·TTS 등 대화에 맞지 않는 모델은 제외).

### v1.2.5

- 설정의 모델/API 목록에서 클라우드 모델(ChatGPT, Claude, Gemini, Grok) 이름 옆에 API 콘솔 바로가기 아이콘(↗)을 추가했습니다. 호버 시 설명 툴팁이 표시되고 클릭하면 해당 제공자의 API 키 관리 페이지가 새 탭으로 열립니다. 로컬 모델에는 표시되지 않습니다.
- start.sh 스크립트를 개선하여 macOS/Linux에서 브라우저 자동 열기(xdg-open/open)를 지원하고, Python 실행 방식을 더 안정적으로 변경했습니다(exec 사용).
- 라이트 테마 지원을 강화했습니다. 사용자 말풍선 내 첨부 파일 배지(.bubble-file), 📝 버튼 하이라이트(.has-custom), 로그인 화면 그라데이션 등이 라이트 모드에서 자연스럽게 표시되도록 수정했습니다.
- 다크 모드에서 채팅 전용 지침(📝) 입력창 배경색과 텍스트 색상이 제대로 적용되지 않던 문제를 수정했습니다.
- 모바일 환경에서 채팅 제목 옆 📝 버튼이 오른쪽 끝으로 밀려 보이던 레이아웃을 제목 바로 뒤에 붙도록 조정했습니다.
- 다크 모드와 모바일 레이아웃 전환 시 여러 UI 요소(모달, 입력창, 버튼, 배지 등)의 스타일 적용 문제를 전반적으로 점검하고 수정했습니다.
- 앱 내 도움말을 최신 변경 사항으로 갱신했습니다.

### v1.2.4

- 채팅 제목 오른쪽에 📝 버튼을 추가했습니다. 클릭하면 해당 채팅에서만 적용되는 전용 시스템 프롬프트를 설정할 수 있는 모달이 열립니다.
- 채팅 전용 프롬프트가 입력되어 있으면 전역 프롬프트(설정 → 개인 맞춤)를 완전히 무시하고, 전용 프롬프트만 시스템 프롬프트로 전송됩니다.
- 전용 프롬프트 설정 모달에 "이 채팅에서 풍부한 응답 서식 (이모지·표·구조화) 사용" 체크박스를 추가했습니다. 체크 여부에 따라 해당 채팅의 API 호출에 이모티콘과 같은 풍부한 서식 지시 포함 여부를 직접 제어합니다 (글로벌 설정 무시).
- 사이드바 채팅 목록에는 📝 배지로, 상단의 📝 버튼 자체가 하이라이트(테두리/색상/작은 점)로 전용 지침이 설정된 채팅을 표시합니다. (상단 제목은 항상 깨끗하게 유지)
- 새 채팅을 누른 직후에도 📝 버튼으로 전용 프롬프트를 바로 설정할 수 있게 했습니다. (첫 메시지 보내기 전부터)
- buildHistory 및 runMaster 로직을 개선해 시스템 프롬프트 우선순위와 채팅별 서식 적용을 정확히 처리하도록 했습니다.
- 마스터 요약이 너무 간결하게 요약되지 않도록 지시문을 보강했습니다.
- 전용 프롬프트는 채팅 메타데이터에 저장되어 동기화·백업·가져오기에 모두 반영됩니다.
- 도움말에 채팅 전용 프롬프트와 풍부한 응답 서식 관련 설명을 추가했습니다.
- 백업 가져오기(import) 시 채팅 전용 프롬프트와 rich 설정이 유실되던 문제를 수정했습니다.
- 개별 모델 응답과 마스터 요약에 타임아웃(기본 60초, settings.timeoutMs로 설정 가능)을 추가했습니다. 응답이 오지 않으면 '타임아웃' 처리되어 무한 대기를 방지합니다.

## 1. 빠른 시작

### 배포 주소로 사용

권장 주소:

```text
https://abandonships.github.io/API-tizer/
```

HTTPS 환경이라 로그인, 암호화, 파일 첨부, 온라인 동기화가 바로 동작합니다.

### 로컬에서 실행

Windows:

```bat
start.bat
```

macOS/Linux:

```bash
./start.sh
```

또는 직접 실행:

```bash
python server.py
```

브라우저에서 `http://localhost:8753`으로 접속합니다.

> 같은 Wi-Fi의 휴대폰에서 `http://PC주소:8753`으로 화면 확인은 가능하지만, 일반 HTTP에서는 Web Crypto가 제한될 수 있습니다. 휴대폰에서 로그인까지 테스트하려면 배포 주소나 HTTPS 터널을 사용하세요.

## 2. 기본 사용법

1. 로그인 화면에서 **온라인** 또는 **이 기기에 저장**을 선택합니다.
2. 계정을 만들고 로그인합니다.
3. **설정 → 모델 / API**에서 사용할 모델의 API 키와 사용 여부를 설정합니다. 모델 이름은 목록에서 고르거나 직접 입력할 수 있습니다.
4. 하단 칩에서 이번 프롬프트에 응답할 모델을 켜고 끕니다.
5. 필요하면 **마스터** 토글을 켜서 지정한 모델이 응답들을 하나로 정리하게 합니다.

마스터 모델은 설정 화면에서 왕관 라디오 버튼으로 지정합니다. 하단 칩에서 왕관 모델을 끄면 마스터 기능도 함께 꺼집니다.

모델 프리셋의 단가는 공개 가격표 기준의 클라이언트 추정값입니다. 제공자 가격은 바뀔 수 있으므로 실제 청구액 확인이 필요하면 각 API 콘솔의 사용량 화면을 기준으로 보세요.

## 3. 온라인 동기화

온라인 모드는 Cloudflare Worker + D1 백엔드에 암호문만 저장합니다. API 키, 설정, 대화 내용은 브라우저에서 암호화된 뒤 동기화됩니다.

기본 동기화 서버:

```text
https://api-tizer-sync.kangmin1152.workers.dev
```

다른 Worker를 쓰려면 로그인 화면의 **동기화 서버 설정**에서 URL을 바꾸면 됩니다. 이 값은 해당 브라우저에만 저장됩니다.

동기화는 다음 시점에 실행됩니다.

- 로그인 직후
- 채팅/설정/백업 가져오기 등 데이터 변경 직후
- 브라우저가 온라인으로 돌아왔을 때
- 백그라운드 주기 동기화
- 사이드바 하단의 **↻ 동기화** 버튼 클릭

## 4. 비밀번호 변경

로컬 계정과 온라인 계정 모두 앱 안에서 비밀번호를 변경할 수 있습니다.

- 로컬 계정: 이 브라우저의 암호화 데이터와 검증 정보가 새 비밀번호 기준으로 바뀝니다.
- 온라인 계정: 먼저 현재 기기를 동기화한 뒤 로컬 데이터를 새 키로 다시 암호화하고, 서버 데이터와 인증 정보를 새 기준으로 덮어씁니다.

온라인 비밀번호 변경 후 다른 기기의 이전 세션은 401을 받고 강제 로그아웃됩니다. 그 기기에서 아직 서버에 올리지 못한 변경분은 병합하지 않습니다.

## 6. Worker 배포

온라인 동기화를 직접 운영하려면 `worker/` 폴더를 Cloudflare에 배포합니다.

요약:

```bash
cd worker
wrangler d1 create api-tizer-sync
wrangler d1 execute api-tizer-sync --remote --file=./schema.sql
wrangler secret put AUTH_SECRET
wrangler deploy
```

기존 v1.1.x D1을 v1.2 이상으로 올리는 경우에는 한 번만 마이그레이션을 적용합니다.

```bash
cd worker
wrangler d1 execute api-tizer-sync --remote --file=./migrations/0001_add_auth_changed_at.sql
wrangler deploy
```

자세한 내용은 [worker/README.md](worker/README.md)를 참고하세요.

## 8. 배포 메모

정적 앱 파일은 GitHub Pages 같은 정적 호스팅에 올릴 수 있습니다.

배포 대상:

- `index.html`
- `styles.css`
- `src/`
- 이미지 파일
- `.nojekyll`
- `README.md`

`worker/`는 GitHub Pages가 아니라 Cloudflare Worker로 별도 배포합니다.

커스텀 API 도메인이나 커스텀 동기화 도메인을 쓰면 `index.html`의 CSP `connect-src`에 해당 도메인을 추가해야 합니다. 응답 본문 이미지 미리보기는 `img-src https:` 범위 안에서만 로드됩니다.

## 9. 제한 사항

- 충돌 해결은 서버에 마지막으로 도달한 변경이 승리하는 방식입니다.
- 온라인 계정의 서버 측 계정 삭제 API는 아직 없습니다. 앱에서는 현재 기기의 데이터 초기화와 서버 동기화 데이터 삭제 표시를 지원합니다.
- 모바일 브라우저에서 화면을 끄거나 다른 앱으로 오래 전환하면 OS가 페이지 실행과 네트워크 스트리밍을 일시 중지할 수 있습니다. 전용 네이티브 앱이나 서버 측 작업 큐 없이 웹 페이지 단독으로 응답 완료를 보장하기는 어렵습니다.
- 자동 로그인은 개인 기기에서만 사용하는 것을 권장합니다. 로그아웃, 비밀번호 변경, 401 강제 로그아웃 시 자동 로그인 정보는 삭제됩니다.
- 저장소에는 API 키, 백업 JSON, `.env`, Worker 로컬 DB 등을 커밋하지 마세요.

## 10. 데이터 보관 위치

- 로컬 모드 설정/API 키: 브라우저 `localStorage`에 암호화 저장
- 온라인 모드 설정/API 키: 브라우저 `IndexedDB`에 암호화 저장 후 서버에 암호문만 동기화
- 대화 기록: 브라우저 `IndexedDB`에 암호화 저장
- 로그인 키: 기본 로그인에서는 메모리에만 보관, 자동 로그인 선택 시 브라우저 저장소에 암호화 저장
