# ![API-tizer 로고](./favicon.png) API-Tizer

**현재 버전: v1.5.6**

ChatGPT · Claude · Gemini · Grok · 로컬 OpenAI 호환 모델을 한 화면에서 동시에 호출하고 비교하는 개인용 멀티 AI 콘솔입니다.

- 여러 모델 동시 응답, 분할/통합 보기, 마스터 요약
- 마스터 요약이 성공한 턴은 후속 질문에 **공식 종합 + 모델별 직전 답**을 함께 넘겨 대화 연속성과 다양성을 유지
- 마스터 요약 옆 **일치/이견 배지**(✓ 일치 · ⚠ 이견)로 모델들이 갈릴 때(환각 의심 신호)를 한눈에 파악
- **마스터 OFF에서도 앙상블 가치** — 답변들의 유사도로 턴마다 일치/갈림 신호(추가 비용 없음)와, 원할 때 🔍 교차검증(한 모델이 “답이 어디서 갈리는지”만 짚어 줌)
- **마스터(집계자) 대체** — 마스터 모델이 타임아웃·실패하면 다른 완료 모델을 골라 요약을 수행할 수 있습니다
- 긴 대화 **자동 압축(컴팩션)** — 대화가 길어져 매 질문에 실리는 이전 맥락이 커지면 안내하고, 이전 대화를 하나의 요약으로 접어 토큰을 절약합니다(채팅 화면 내용은 그대로 유지). 상단 🗜 대화 압축 버튼으로 언제든 수동 실행 가능
- 토큰 절약형 히스토리 관리 — 최근 대화는 원문, 오래된 대화는 공식 종합만, 첨부(이미지·PDF)는 최근 것만 재전송
- 이미지 · 텍스트 · PDF 첨부
- 웹 검색 지원 모델의 출처 표시, 본문 URL 자동 링크화, 이미지 링크 미리보기
- 설정의 "풍부한 응답 서식" (기본 ON)으로 API 호출 시에도 이모지·표·구조화된 답변 유도
- 채팅별 📝 전용 프롬프트 지원 — 채팅 제목 옆 📝 버튼으로 특정 채팅에서만 적용되는 시스템 프롬프트 설정 가능 (설정 시 전역 취향 프롬프트를 대체, 플랫폼 기본 연속성 지시는 유지)
- 채팅 전용 프롬프트 설정 시 풍부한 응답 서식(이모지·표·구조화) on/off를 독립적으로 제어 가능
- 모델 응답 및 마스터 요약 타임아웃 + 진행 중 완료된 모델만 선택해 즉시 요약 실행 지원
- 최대 응답 토큰 설정(기본 8192) — Claude처럼 상한이 필수인 모델의 긴 요약·답변이 잘리지 않도록 조정 가능
- 모델별 토큰/비용 추정치 누적 및 접이식 비용 패널
- 주요 제공자 모델 프리셋과 단가 자동 입력
- 로컬 암호화 저장 또는 Cloudflare Worker 기반 온라인 동기화
- **읽기 전용 공유 링크** — 대화를 링크 하나로 공유. 링크를 가진 사람은 로그인 없이 그 대화만 볼 수 있고, 복호화 키는 링크 안(URL `#`)에만 있어 서버엔 암호문만 저장됩니다. 공유는 그 시점의 고정 스냅샷이며 7일 후 자동 만료
- **한국어 / English UI** — 로그인 화면 또는 설정에서 전환
- PC/모바일 레이아웃 자동 전환 및 수동 고정

## English

**API-Tizer** is a personal multi‑AI console that calls and compares ChatGPT · Claude · Gemini · Grok and local OpenAI‑compatible models on a single screen.

- Simultaneous responses from multiple models, split/unified views, and a master summary
- On turns where the master summary succeeded, follow‑up questions carry both the **official synthesis + each model's own previous answer** to preserve continuity and diversity
- A **match/dissent badge** next to the master summary (✓ Match · ⚠ Dissent) shows at a glance when the models diverge (a possible hallucination signal)
- **Ensemble value even with master OFF** — a per‑turn agree/diverge signal from answer similarity (no extra cost), plus on‑demand 🔍 Cross‑check where one model points out only "where the answers differ"
- **Aggregator fallback** — if the master model times out or fails, another finished model can write the summary instead
- **Automatic compaction** for long chats — when the prior context sent with every question grows large, it offers to fold earlier turns into a single summary to save tokens (the on‑screen chat stays intact); a 🗜 Compact‑chat button allows manual runs anytime
- Token‑saving history — recent turns verbatim, older turns as the official synthesis only, and attachments (images/PDFs) re‑sent only for the most recent turns
- Image · text · PDF attachments
- Sources for web‑search‑capable models, automatic in‑text URL linkification, and image‑link previews
- "Rich formatting" (on by default) yields emoji/tables/structured answers even on API calls
- Per‑chat 📝 dedicated prompt — a system prompt applied only to a specific chat (replaces the global taste prompt; the platform continuity instruction is kept), with independent rich‑formatting on/off per chat
- Model‑response & master‑summary timeout + summarize immediately using only the finished models
- Max response tokens — adjustable so long summaries/answers aren't truncated on models like Claude that require a cap
- Per‑model token/cost estimates accumulated with a collapsible cost panel
- Presets and pricing for major providers auto‑filled
- Local encrypted storage or Cloudflare Worker‑based online sync
- **Read‑only share links (zero‑knowledge)** — share a conversation as a link. Anyone with the link can view just that chat without logging in; the decryption key lives only in the link (URL `#`), so the server stores ciphertext only. A share is a frozen snapshot and auto‑expires after 7 days
- **한국어 / English UI** — switch on the login screen or in Settings
- Automatic PC/mobile layout switching with manual override

## 변경 사항

### v1.5.6

- **Grok이 크레딧 소진으로 실패할 때 원인을 바로 알 수 있게 했습니다.** xAI는 팀 크레딧이 떨어지거나 월 지출 한도에 닿으면 `HTTP 403 permission-denied`로 응답하는데, 이전에는 날것의 JSON(`{"code":"permission-denied",...}`)만 보여 API 키 문제로 오해하기 쉬웠습니다. 이제 에러 내용을 사람 읽는 문장으로 뽑아 보여주고, 크레딧 소진이면 **충전/한도 안내**(https://console.x.ai/)를 함께 표시합니다. 이는 **결제 문제라 앱 설정으로 해결되지 않습니다** — 크레딧을 충전하거나 지출 한도를 올려야 Grok 호출이 다시 됩니다.
- **Grok 웹 검색의 불필요한 재시도를 없앴습니다.** 인증·결제 실패(401/403)에는 일반 채팅으로 폴백하지 않고 즉시 에러를 보여줍니다(같은 키·잔액이라 어차피 똑같이 실패하므로). 빈 응답이나 일시 오류 때의 폴백·자동 재시도는 그대로입니다.
- **타임아웃 안내 문구를 실제 동작과 맞췄습니다.** v1.5.2부터 타임아웃은 유휴(idle) 방식이고 기본값은 120초인데, 도움말·설정 팁에 60초로 남아 있던 표기를 고쳤습니다.

### v1.5.5

- **답변의 마크다운이 일부 깨지던 문제를 고쳤습니다.**
- **느린 모델이 아직 답하는 중인데 "다른 모델로 요약" 팝업이 먼저 뜨던 문제를 고쳤습니다.** GPT·Grok처럼 오래 스트리밍하는 모델이 **활발히 답하는 중**인데도 내부 "진행 해제" 타이머가 고정 시간(기본 120초)이라 조기 발동해 마스터 요약을 미완성 상태에서 시작하려 했습니다. 이제 이 타이머도 **유휴(idle) 방식**(스트림 활동 시 계속 리셋)으로 바뀌어, 모든 모델이 끝나면 요약이 **자동 실행**됩니다.

### v1.5.4

- **로그인 화면에 현재 버전을 표시합니다.** 접속했을 때 지금 실행 중인 버전(예: `v1.5.4`)을 로그인 카드 하단에서 바로 확인할 수 있어, 브라우저가 예전 버전을 캐시하고 있는지 등을 쉽게 알 수 있습니다.
- **Grok 웹 검색을 xAI의 새 Agent Tools API로 전환했습니다.** v1.5.3에서 쓰던 `search_parameters`(Live Search)가 폐기되어, 웹 검색을 켠 Grok 호출이 `HTTP 410`으로 실패했습니다. 이제 Responses 엔드포인트 + `web_search` 툴로 호출하고, 혹시 검색 경로가 비면 자동으로 일반 채팅으로 폴백해 **최소한 답변은 나오도록** 했습니다.

### v1.5.3

- **각 제공자의 최신 모델을 조사해 반영했습니다.** 공식 문서 기준으로 새 모델을 프리셋·기본값·단가 표에 추가하고, 바뀌어있던 단가를 최신화했습니다.
  - **Gemini 3.8 Flash**(`gemini-3.8-flash`) — 최신 Flash 모델을 추가하고 기본 Gemini 모델로 지정했습니다(입력 100만 토큰당 $1.5 / 출력 $7.5).
  - **GPT-6 Astra**(`gpt-6-astra`) — OpenAI 신규 플래그십 모델을 추가했습니다(입력 $10 / 출력 $50).
  - **Claude Opus 5**(`claude-opus-5`, 입력 $5 / 출력 $25)·**Claude Fable 5.1**(`claude-fable-5-1`, 입력 $10 / 출력 $50) — Anthropic 신규 모델을 추가했습니다.
  - **변경된 단가를 최신화**했습니다: GPT-5.6 Terra($2.5/$15→$2/$12), GPT-5.6 Luna($1/$6→$0.2/$1.2), Claude Sonnet 5($3/$15→$2/$10).
- **Grok이 계속 “응답 없음”으로 끝나던 문제를 고쳤습니다.** 웹 검색이 켜져 있을 때(기본값) Grok을 OpenAI Responses API로 호출하던 것이 원인으로, xAI에서 빈 응답이 돌아왔습니다. 이제 xAI 공식 방식인 `/chat/completions`의 `search_parameters`(라이브 검색)로 호출해 **정상적으로 답변과 출처가 나오도록** 고쳤습니다.

### v1.5.2

- **추론(reasoning) 모델이 “생각”하는 동안 응답이 잘못 타임아웃되던 문제를 개선했습니다.** Grok 4.6처럼 답변 전에 오래 추론하는 모델은 눈에 보이는 텍스트가 나오기까지 시간이 걸리는데, 이전에는 그 시간이 타임아웃(기본 60초)을 넘기면 응답이 끊겼습니다. 이제 **모델 응답·마스터 요약·교차검증 타임아웃이 “유휴(idle) 방식”으로 바뀌어**, 모델이 무언가를 스트리밍하는 동안(추론 이벤트 포함)에는 타임아웃이 계속 리셋되고, **정말로 아무 신호도 없을 때만** 발동합니다.
  - **기본 응답 타임아웃을 60초 → 120초로 늘렸습니다.** (이미 사용 중이던 설정값은 그대로 유지되며, 유휴 리셋은 설정값과 무관하게 적용됩니다. 설정에서 언제든 조정할 수 있습니다.)

  - **이미지 포함 선택** — 기본은 텍스트만 공유하며, 필요하면 이미지를 압축(최대 1280px)해 함께 담을 수 있습니다. 용량이 크면 텍스트만 공유하도록 안내합니다.

### v1.4.2

HTTPS 환경이라 로그인, 암호화, 파일 첨부, 온라인 동기화가 바로 동작합니다.

### 로컬에서 실행

Windows:

```bat
start.bat
```

macOS/Linux:

```bash
./start.sh
```

또는 직접 실행:

```bash
python server.py
```

브라우저에서 `http://localhost:8753`으로 접속합니다.

> 같은 Wi-Fi의 휴대폰에서 `http://PC주소:8753`으로 화면 확인은 가능하지만, 일반 HTTP에서는 Web Crypto가 제한될 수 있습니다. 휴대폰에서 로그인까지 테스트하려면 배포 주소나 HTTPS 터널을 사용하세요.

## 2. 기본 사용법

1. 로그인 화면에서 **온라인** 또는 **이 기기에 저장**을 선택합니다.
2. 계정을 만들고 로그인합니다.
3. **설정 → 모델 / API**에서 사용할 모델의 API 키와 사용 여부를 설정합니다. 모델 이름은 목록에서 고르거나 직접 입력할 수 있습니다.
4. 하단 칩에서 이번 프롬프트에 응답할 모델을 켜고 끕니다.
5. 필요하면 **마스터** 토글을 켜서 지정한 모델이 응답들을 하나로 정리하게 합니다.

마스터 모델은 설정 화면에서 왕관 라디오 버튼으로 지정합니다. 하단 칩에서 왕관 모델을 끄면 마스터 기능도 함께 꺼집니다.

모델 프리셋의 단가는 공개 가격표 기준의 클라이언트 추정값입니다. 제공자 가격은 바뀔 수 있으므로 실제 청구액 확인이 필요하면 각 API 콘솔의 사용량 화면을 기준으로 보세요.

## 3. 온라인 동기화

온라인 모드는 Cloudflare Worker + D1 백엔드에 암호문만 저장합니다. API 키, 설정, 대화 내용은 브라우저에서 암호화된 뒤 동기화됩니다.

기본 동기화 서버:

```text
https://api-tizer-sync.kangmin1152.workers.dev
```

다른 Worker를 쓰려면 로그인 화면의 **동기화 서버 설정**에서 URL을 바꾸면 됩니다. 이 값은 해당 브라우저에만 저장됩니다.

동기화는 다음 시점에 실행됩니다.

- 로그인 직후
- 채팅/설정/백업 가져오기 등 데이터 변경 직후
- 브라우저가 온라인으로 돌아왔을 때
- 백그라운드 주기 동기화
- 사이드바 하단의 **↻ 동기화** 버튼 클릭

## 4. 비밀번호 변경

로컬 계정과 온라인 계정 모두 앱 안에서 비밀번호를 변경할 수 있습니다.

- 로컬 계정: 이 브라우저의 암호화 데이터와 검증 정보가 새 비밀번호 기준으로 바뀝니다.
- 온라인 계정: 먼저 현재 기기를 동기화한 뒤 로컬 데이터를 새 키로 다시 암호화하고, 서버 데이터와 인증 정보를 새 기준으로 덮어씁니다.

온라인 비밀번호 변경 후 다른 기기의 이전 세션은 401을 받고 강제 로그아웃됩니다. 그 기기에서 아직 서버에 올리지 못한 변경분은 병합하지 않습니다.

## 5. 백업

**설정 → 보안 & 백업**에서 별도 백업 암호로 전체 데이터를 암호화한 JSON 파일을 만들 수 있습니다.

- 내보내기: 설정, API 키, 모델 설정, 사용량, 대화 기록 포함
- 가져오기: 현재 계정에 채팅을 추가하고, 원하면 설정도 덮어쓰기
- 백업 암호를 잊으면 백업 파일을 복구할 수 없습니다.

## 6. Worker 배포

온라인 동기화를 직접 운영하려면 `worker/` 폴더를 Cloudflare에 배포합니다.

요약:

```bash
cd worker
wrangler d1 create api-tizer-sync
wrangler d1 execute api-tizer-sync --remote --file=./schema.sql
wrangler secret put AUTH_SECRET
wrangler deploy
```

기존 v1.1.x D1을 v1.2 이상으로 올리는 경우에는 한 번만 마이그레이션을 적용합니다.

```bash
cd worker
wrangler d1 execute api-tizer-sync --remote --file=./migrations/0001_add_auth_changed_at.sql
wrangler deploy
```

자세한 내용은 [worker/README.md](worker/README.md)를 참고하세요.

## 8. 배포 메모

정적 앱 파일은 GitHub Pages 같은 정적 호스팅에 올릴 수 있습니다.

배포 대상:

- `index.html`
- `styles.css`
- `src/`
- `vendor/` (번들된 pdf.js)
- 이미지 파일
- `.nojekyll`
- `README.md`

`worker/`는 GitHub Pages가 아니라 Cloudflare Worker로 별도 배포합니다.

커스텀 API 도메인이나 커스텀 동기화 도메인을 쓰면 `index.html`의 CSP `connect-src`에 해당 도메인을 추가해야 합니다. 응답 본문 이미지 미리보기는 `img-src https:` 범위 안에서만 로드됩니다.

## 9. 제한 사항

- 충돌 해결은 서버에 마지막으로 도달한 변경이 승리하는 방식입니다.
- 온라인 계정의 서버 측 계정 삭제 API는 아직 없습니다. 앱에서는 현재 기기의 데이터 초기화와 서버 동기화 데이터 삭제 표시를 지원합니다.
- 모바일 브라우저에서 화면을 끄거나 다른 앱으로 오래 전환하면 OS가 페이지 실행과 네트워크 스트리밍을 일시 중지할 수 있습니다. 전용 네이티브 앱이나 서버 측 작업 큐 없이 웹 페이지 단독으로 응답 완료를 보장하기는 어렵습니다.
- 자동 로그인은 개인 기기에서만 사용하는 것을 권장합니다. 로그아웃, 비밀번호 변경, 401 강제 로그아웃 시 자동 로그인 정보는 삭제됩니다.
- 저장소에는 API 키, 백업 JSON, `.env`, Worker 로컬 DB 등을 커밋하지 마세요.
