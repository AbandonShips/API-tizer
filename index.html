설정

개인 맞춤 (전역 시스템 프롬프트) ?

모든 대화에 적용되는 기본 시스템 프롬프트입니다. 특정 채팅에서 '📝' 버튼으로 전용 프롬프트를 설정하면, 전역 프롬프트는 그 채팅에서 완전히 무시됩니다.

모델 / API ?

마스터로 지정한 모델이 모든 답변을 하나로 정리하고 소수 의견을 덧붙입니다. 로컬은 최대 3개까지 추가할 수 있어요 (Ollama / LM Studio 등 OpenAI 호환).

표시 옵션

언어 (Language)

앱 화면과 AI에게 보내는 지시문 언어를 바꿉니다. 기기 단위로 저장됩니다.

보안 & 백업 ?

백업 파일은 별도 백업 암호로 암호화됩니다. 이 암호를 알면 다른 브라우저나 PC에서도 복원할 수 있습니다.

저장소 & 초기화 ?

저장 공간 정보를 불러오는 중…

아래 작업은 현재 사용자에게만 적용되며 되돌릴 수 없습니다. 대화내용 초기화는 채팅 기록만 지우고, 데이터 초기화는 API 키 · 설정 · 채팅 기록을 모두 지웁니다.

비밀번호 변경

변경하면 모든 데이터가 새 비밀번호로 다시 암호화됩니다. 잠시 시간이 걸릴 수 있습니다.

기능 안내

  • 마스터 요약 (ON) — 지정한 한 모델이 나머지 답을 하나로 합쳐 최종 답을 만들어 줍니다. 답들이 서로 맞으면 ✓ 일치, 갈리면 ⚠ 이견 배지가 붙어 어디가 미심쩍은지 바로 보입니다.
  • 마스터 요약 (OFF) — 각 모델 답을 그대로 나란히 봅니다. 답들이 얼마나 비슷한지 막대로 알려주고, 모든 답이 도착하면 🔍 교차검증 버튼이 켜져 한 모델이 “어디가 같고 어디가 다른지”만 짚어 줍니다.
  • 🌐 웹 검색 — 켜면 최신 정보를 인터넷에서 찾아 출처와 함께 답합니다. 끄면 모델이 이미 아는 지식으로만 답합니다.
  • ⬛ 분할 / ▤ 통합 — 분할은 모델별 답을 나란히, 통합은 한 컬럼으로 모아서 봅니다.
  • 🗜 대화 압축 — 대화가 길어지면 상단 🗜 대화 압축 버튼으로 이전 내용을 짧게 요약해 둡니다. 화면 대화는 그대로 남고, 다음 질문부터 토큰(비용)이 줄어듭니다.
  • ⏱️ 타임아웃 — 한 모델이 정한 시간(기본 60초) 안에 답을 안 주면 기다리지 않고 넘어갑니다. 마스터가 실패하면 다른 완료된 모델에게 요약을 대신 맡길 수 있습니다.
  • 📝 채팅별 지침 — 제목 옆 📝 버튼으로 이 채팅에서만 쓸 말투·규칙을 정합니다.
  • 📚 자주 쓰는 프롬프트 — 즐겨 쓰는 문구를 저장해 두고 입력창에 한 번에 넣습니다.
  • ✨ 풍부한 서식 — 켜면(기본) 답변에 표·이모지·소제목이 들어가 읽기 편하고, 끄면 담백한 글로 나옵니다.
  • 💰 토큰·비용 — 답변마다 예상 사용량과 대략적 비용을 표시합니다(설정에서 끄기 가능). 켜진 모델이 많고 대화가 길수록, 첨부·웹 검색을 쓸수록 늘어납니다.
  • 📎 첨부 — 이미지·PDF·텍스트 파일을 붙여 질문할 수 있습니다(이미지는 비전 지원 모델만).
  • 💻 코드 · 출처 [n] — 답변 속 코드는 「복사」로 한 번에 복사하고, 출처 번호를 누르면 원문이 새 탭으로 열립니다.
  • 🌙 테마 · 📌 고정 · 📁 폴더 — 우상단에서 다크·라이트를 바꾸고, 채팅을 상단 고정하거나 폴더로 정리합니다.

📱 모바일 · 화면 전환

  • 상단 전환 버튼 — 상단 바의 🖥️ / 📱 버튼으로 PC·모바일 레이아웃을 직접 고정할 수 있습니다. 다시 누르면 자동 모드로 돌아갑니다.
  • 모바일 입력 — Enter는 줄바꿈이고, 전송은 하단 전송 버튼으로 합니다.
  • 모바일 제스처 — 화면 왼쪽/중앙 왼쪽에서 오른쪽으로 밀면 대시보드가 열리고, 열린 상태에서 왼쪽으로 밀면 닫힙니다.
  • 권장 접속 방식 — 배포 주소(https://abandonships.github.io/API-tizer/)로 접속하면 HTTPS 환경에서 로그인·암호화·온라인 동기화를 바로 사용할 수 있습니다.
  • 로컬 개발에서 휴대폰 접속 — 같은 와이파이의 http://(PC주소):8753 는 화면 확인용으로는 가능하지만, 일반 HTTP 특성상 로그인·암호화가 제한될 수 있습니다. 실제 로그인 테스트는 HTTPS 터널(cloudflared/ngrok) 또는 배포 주소를 사용하세요.
  • 동기화 서버 — 로그인 화면의 동기화 서버 설정에서 Worker URL을 바꾸면 해당 기기에서만 다른 서버를 사용합니다.
