도움말 · 단축키

단축키

  • Ctrl+N — 새 채팅
  • Ctrl+K — 채팅 검색으로 이동
  • Enter — 전송 · Shift+Enter — 줄바꿈
  • Esc — 열린 창 닫기 / 이름 변경 취소

기능 안내

  • 마스터 요약 — 지정한 모델이 모든 답을 하나로 정리하고 소수 의견을 덧붙입니다.
  • 🌐 웹 검색 — 지원 모델(ChatGPT·Claude·Gemini·Grok)이 실시간 검색 후 출처를 답니다.
  • � 프롬프트 라이브러리 — 자주 쓰는 프롬프트를 저장해 두고 입력창에 한 번에 넣습니다.
  • 📌 고정 / 📁 폴더 — 채팅을 상단 고정하거나 폴더로 분류합니다.
  • 토큰·비용 — 답변 헤더에 추정 토큰 수와 대략적 비용을 표시합니다(설정에서 끄기 가능).
  • 출처 [n] — 본문의 각주 번호를 클릭하면 해당 출처가 새 탭으로 열립니다.
  • 💻 코드블록 — 답변의 코드는 문법 강조 + 「복사」 버튼으로 한 번에 복사합니다.
  • 🌙 / ☀️ 테마 — 우상단 버튼으로 다크·라이트 화면을 전환합니다.

📱 모바일 · 화면 전환

  • 오른쪽 아래 버튼 — 🖥️ PC 보기 / 📱 모바일 보기 로 레이아웃을 직접 바꿉니다. 화면 크기에 따라 자동으로도 전환됩니다.
  • 휴대폰 접속 — 같은 와이파이에서 http://(PC주소):8753 로 접속합니다. 서버를 켜면 콘솔에 정확한 주소가 표시됩니다.
  • 주의 — 보안 정책상 localhost 가 아닌 일반 http 주소에서는 로그인·암호화가 막힐 수 있습니다. 휴대폰에서 제대로 쓰려면 HTTPS 터널(cloudflared·ngrok 등)이 필요합니다.
